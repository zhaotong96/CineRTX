### 夹具生成的非显然约束（已写入测试源码注释）

`tests/test_playback_session.cpp:120-135`：视频轨必须先生成**无音轨** MKV，再与音轨
`-c copy` 合流。一次性编码音视频时 Matroska 复用器会把视频整体后移一个 AAC 编码器
priming（实测 21 ms：首帧 PTS 0.021 s），此后所有帧都不落在 40 ms 网格上，
帧精确 seek 与逐帧步进的严格相等断言随之失效。
另：25 fps 的 40 ms 帧周期在 Matroska 固定 1 ms TimecodeScale 下无损，24 fps 的
41.667 ms 会被量化抖动，故夹具选 25 fps。

### 软限幅器有界性的构造性证明（无需后置钳位）

拐点 `t = 0.75f` 与余量 `k = 0.25f` 都是精确二进制分数，`t + k == 1.0f` 在 float 下精确成立。
对 `|x| > t`：令 `a = |x| − t > 0`，则 `q = fl(k·a / (k + a))`。因 `k·a/(k+a) < k` 恒成立，
就近舍入至多把 `q` 抬到 `k`，故 `fl(t + q) ≤ 1.0f`。输出可证落在 `[-1, 1]`，
因此实现里**没有**也不需要一个防御性后置 clamp。

### WSOLA 保调机理与实测

分析网格 `ta_k = k·Ha`，`Ha = Hs·speed`；理想偏移 `δ_k ≈ δ_{k−1} + Hs(1−speed)` 会漂移并
在 ±search 处饱和，但归一化互相关把 `δ` 拉回信号周期的整数倍，故基频不变。
输出长度 `(K−1)·Hs + N ≈ n_in/speed + Hs`，多出的半窗是 OLA 淡出尾巴——这也是短输出
相对误差偏大的原因，测试据此采用 `expected_ratio*0.02 + 960/n_in` 的有理容差
（`tests/test_audio_mixer_avx2.cpp:446-447`），而非放宽门禁。

### 本轮定位并修复的真实缺陷

| 缺陷 | 根因 | 修复锚点 |
| --- | --- | --- |
| **堆损坏 `0xC0000374` → 访问违例 `0xC0000005`**（`audio_spsc_ring_wraps_without_loss` 第 2 轮） | 单一助手 `copyPlane(base, src, offset, …)` 执行 `memcpy(base + offset, src, …)`，该式只在 `base` 是**环**平面时成立。`read()` 把线性目标 `dst.left.data()`（37 float = 148 B）当作 base 传入 offset=37，越界写 108 B。第 0 轮 offset=0 恰好合法，故只崩在第 2 轮；跨线程测试靠 vector 余量侥幸存活 | `audio_mixer_avx2.cpp:27`/`:36` 拆成方向明确的 `copyToRing` / `copyFromRing`，与 `src/core/wasapi_audio_output.cpp:297`/`:307` 同构 |

### C4324 警告的归因（先存约定，非缺陷）

新增 `alignas(64)` 游标触发 `warning C4324: structure was padded due to alignment specifier`。
未加任何抑制，而是先取证：远程 touch `src/core/wasapi_audio_output.cpp` 后重建，
同一警告亦出现在 `include/rtx/telemetry_bus.h:30`（TelemetrySnapshot）、`:76`（AtomicTelemetryBus）、

结论：这是全项目对**有意缓存行填充**的既有编译约定，正是 09 号施工单第 2 条要求的物理隔离，
故保留警告原样。
